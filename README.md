# Deep Research - Antimicrobial Resistance

# Getting Started
1. Install `uv` package manager: [instructions](https://docs.astral.sh/uv/)
2. Copy `example.env` into the root directory and name it `.env`
3. Add your Perplexity API Key and add some credits
4. Run `uv run main.py`
5. You should see the relevant results in `policy_summaries.tsv`
